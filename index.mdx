Roki AI generates SEO-optimized articles and delivers them straight into the tools you already use. These guides walk you through connecting TryRoki to your stack so new content publishes automatically — no manual copying, no CSV exports.

## Integrations

<CardGroup cols={2}>
  <Card title="Webhooks" icon="webhook" href="/webhooks/overview">
    Receive real-time HTTP POST notifications whenever TryRoki publishes or updates an article. Connect to any endpoint — your own server, Zapier, Make.com, or Pabbly Connect.
  </Card>
  <Card title="WordPress" icon="wordpress" href="/wordpress">
    Automatically publish TryRoki articles to your WordPress site using the Tryroki plugin. Handles content, featured images, and post status — no credentials required.
  </Card>
  <Card title="Lovable" icon="heart" href="/lovable">
    Connect TryRoki to your Lovable site with a single prompt and have AI-generated blog posts published automatically.
  </Card>
  <Card title="Next.js" icon="react" href="/nextjs">
    Wire TryRoki into a Next.js App Router site — one webhook route and a blog. Written so your AI coding agent can do it end to end.
  </Card>
</CardGroup>
