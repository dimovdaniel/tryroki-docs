description: "Choose your AI app and connect it to TryRoki so it can create and update articles."

TryRoki's MCP server lets AI apps work with your Roki AI articles. After you connect it, the AI app can create new imported articles, update articles it previously imported, search your article list, and fetch article content.

Start in the [TryRoki MCP integration page](https://app.tryroki.com/contentgen/integrations/mcp). It shows your server URL, API key, connect token, and ready-to-paste `mcp.json`.

## What you need

- A TryRoki account with access to the workspace you want to connect.
- The server URL: `https://app.tryroki.com/mcp/articles`
- Your API key or connect token from the TryRoki dashboard.
- The AI app you want to connect.

<Warning>
  Treat your API key and connect token like passwords. Anyone with either credential can use your workspace's MCP article tools.
</Warning>

## When setup is done

Open your AI app and ask it to use TryRoki to list your articles. If it can see the TryRoki tools and list articles from your workspace, the connection is working.

If setup fails, use the [MCP troubleshooting guide](/mcp/troubleshooting).
